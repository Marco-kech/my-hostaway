1. Prise en main

1.1 Les 4 interfaces de My Hostaway

My Hostaway comprend 4 interfaces distinctes, chacune adaptée à un profil d'utilisateur :

🏢 Interface Admin (cette interface)

URL : /my-hostaway/

Pour : L'équipe DPM (vous, Laurent, gestionnaires)

Accès : Toutes les rubriques, toutes les données, tous les biens, tous les partenaires et propriétaires

Droits : Création, modification, suppression, validation des comptes, configuration

🤝 Interface Partenaire

URL : /my-hostaway/partenaire/

Pour : Les prestataires externes (spa, transport, excursions…)

Accès : Uniquement ses propres prestations, commandes reçues et statistiques

Droits : Consultation. Si « Peut modifier ses prestations » est activé dans sa fiche : peut ajuster prix et descriptions. Si « Peut créer des promotions » : peut créer des offres spéciales.

Création du compte : Le partenaire demande un accès depuis l'URL ci-dessus. L'admin valide sa demande dans Comptes & accès et rattache le compte à sa fiche partenaire.

🏠 Interface Propriétaire

URL : /my-hostaway/proprietaire/

Pour : Les propriétaires des biens en gestion

Accès : Ses biens, ses réservations, ses revenus, ses prestations internes

Droits : Consultation uniquement (sauf droits spécifiques activés par l'admin)

Création du compte : Même processus que le partenaire : demande depuis l'URL, validation par l'admin.

✈️ Interface Voyageur

URL : /my-hostaway/sejour/#/s/{token}

Pour : Le voyageur pendant son séjour

Accès : Informations du logement (adresse, wifi, code porte, instructions), catalogue des prestations disponibles pour ce bien, formulaire de commande, suivi de ses demandes

Droits : Consultation + commande de prestations

Pas de compte : Accès par lien unique généré par l'admin. Le lien expire 30 jours après le départ.

3. Calendrier — 3 vues

3.1 Vue Multiple (tous les biens)

Tous vos biens sont affichés côte à côte sur une frise temporelle horizontale. Chaque réservation est une barre colorée :

CouleurStatut
VertRéservation confirmée
JauneDemande en attente
RougeAnnulée
GrisBloqué / séjour propriétaire

Glissez horizontalement pour naviguer dans le temps. Cliquez sur une barre pour ouvrir la fiche de réservation.

3.2 Vue Mensuelle

Calendrier classique mois par mois. Chaque jour montre les réservations positionnées. Cliquez sur un jour vide pour créer une réservation manuelle. Cliquez sur une réservation pour ouvrir sa fiche.

Utilisez les flèches ← → pour changer de mois. Le filtre « Bien » permet d'afficher un seul bien.

3.3 Vue Annuelle (taux d'occupation)

Grille 12 mois × nombre de biens. Chaque cellule est colorée selon le taux d'occupation du mois :

  • Vert foncé : occupation > 75% (très bon)
  • Vert clair : occupation 50-75% (correct)
  • Orange : occupation 25-50% (à améliorer)
  • Rouge : occupation < 25% (alerte)

Idéal pour repérer les périodes creuses et ajuster les tarifs ou lancer des promotions.

4. Boîte de réception — Messagerie complète

4.1 Conversations

Tous les échanges centralisés. Les messages des plateformes (Airbnb, Booking, WhatsApp) arrivent ici avec la photo et le nom du voyageur, rattachés à la réservation.

Chaque conversation affiche :

  • Le nom du voyageur et sa photo
  • Le bien et les dates de sa réservation
  • Le canal d'origine (Airbnb, Booking, WhatsApp, direct)
  • Le dernier message avec son heure
  • Un badge Non lu si le message n'a pas été vu

Répondez directement depuis l'application : le message est envoyé sur la plateforme d'origine.

5.2 Accepter ou refuser une demande

Les réservations importées depuis les plateformes arrivent en statut « demande » (inquiry Airbnb) ou « en_attente » (booking request).

1
Dans la liste, repérez la réservation avec le statut jaune « demande » ou « en_attente »
2
Cliquez ✅ Accepter pour confirmer la réservation. Les dates sont bloquées dans le calendrier, la plateforme est synchronisée.
3
Ou cliquez ❌ Refuser pour rejeter la demande. La plateforme est notifiée.
✅ Conseil : Répondez rapidement aux demandes Airbnb (< 24h) pour maintenir votre taux de réponse et votre classement.

5.3 Fiche de réservation

Cliquez sur le bouton 👁 d'une réservation pour ouvrir sa fiche complète. Vous y trouvez :

  • Les informations du séjour (dates, nombre de nuits, prix/nuit calculé)
  • Le voyageur (nom, email, téléphone, avec lien vers sa fiche voyageur)
  • Le bien (nom, propriétaire)
  • Le statut du paiement
  • Les commandes de prestations rattachées à ce séjour
  • L'historique des messages échangés

5.4 Contrat PDF automatique

Cliquez sur le bouton 📄 d'une réservation. L'application génère automatiquement un contrat de location au format PDF avec :

  • En-tête aux couleurs DPM
  • Identification des parties (propriétaire + voyageur)
  • Description du bien
  • Dates et durée du séjour
  • Montant total, prix/nuit, conditions de paiement
  • Conditions d'annulation
  • Zone de signature

5.5 Check-in en ligne

  • Pièce d'identité (photo + numéro)
  • Heure d'arrivée prévue
  • Nombre exact de personnes
  • Selfie (si activé)

Allez dans Réservations → Check-in en ligne pour voir l'état de chaque check-in (en attente, complété, vérifié) et télécharger les documents.

15. Conciergerie — Prestations

Les prestations sont le cœur de l'activité conciergerie DPM. Ce chapitre explique chaque aspect en détail.

15.1 Les 3 types de prestations

🤝 Type « Externe » (Partenaire)

Un prestataire externe fournit le service. DPM fait l'intermédiaire :

  • DPM vend la prestation au voyageur au prix facturé
  • DPM reverse au partenaire le net partenaire
  • DPM conserve la commission (prix − net)

Exemples : massage, quad, transfert aéroport, guide privé, golf

🏠 Type « Interne » (Propriétaire)

Le propriétaire fournit le service via son personnel (cuisinier, femme de ménage…). DPM prend une commission fixée par bien (champ « commission_prestation_pct » dans la fiche du bien, défaut 20%).

Exemples : petit-déjeuner, dîner privé, ménage supplémentaire, blanchisserie

🏢 Type « DPM »

DPM source et fournit directement la prestation. Pas de reversement partenaire. Le coût de revient est suivi pour calculer la marge interne.

Exemples : service de conciergerie personnalisé, organisation d'événements, service DPM exclusif

15.3 Tarifs, commissions et net partenaire — avec exemples

Exemple 1 — Prestation externe avec commission en %
Massage bien-être proposé au logement :
• Prix facturé au voyageur : 600 DH
• Commission DPM : 15 %
• Calcul : 600 × 15% = 90 DH de commission
• Net partenaire : 600 − 90 = 510 DH

Le voyageur commande 2 massages :
• Total facturé : 2 × 600 = 1 200 DH
• Commission DPM : 2 × 90 = 180 DH
• À reverser au partenaire : 2 × 510 = 1 020 DH
Exemple 2 — Prestation interne (propriétaire)
Petit-déjeuner livré à la villa :
• Prix facturé au voyageur : 150 DH / personne
• Commission DPM : fixée par le bien (ex : 20%)
• Le propriétaire reçoit 80% du montant
• DPM retient 20%

4 personnes commandent le petit-déjeuner :
• Total facturé : 4 × 150 = 600 DH
• Part propriétaire : 600 × 80% = 480 DH
• Commission DPM : 600 × 20% = 120 DH
Exemple 3 — Prestation sans commission (net = prix)
Transfert aéroport :
• Prix facturé au voyageur : 250 DH / trajet
• Commission DPM : 0
• Net partenaire : 250 DH (tout va au chauffeur)
→ DPM ne prend rien sur cette prestation, c'est un service rendu au voyageur pour fidéliser.

Comment modifier le prix d'une prestation ?

Allez dans Conciergerie → Toutes les prestations → cliquez ✏️ sur la prestation → modifiez le prix → Enregistrer. Les nouvelles commandes utiliseront le nouveau prix.

Annonces → Liste → ✏️ sur le bien → champ « Commission sur les services vendus par le propriétaire (%) » → Enregistrer.

Comment exporter mes données ?

Dans toute liste (réservations, prestations, partenaires…), cliquez le bouton ⬇ CSV en haut à droite de la liste. Le fichier se télécharge directement.

A. Un nouveau bien arrive — de A à Z

Un propriétaire confie la gestion de son riad à DPM. Voici toutes les étapes dans l'application :

1
Créer le propriétaire — Conciergerie → Propriétaires → + Ajouter. Remplissez la fiche : nom, email, téléphone, coordonnées bancaires pour les reversements.
2
Créer le bien — Annonces → + Ajouter un bien. Remplissez les 9 sections : identité (nom, type, rattachement au propriétaire), description, localisation, capacité, tarifs (prix/nuit, ménage, caution), arrivée & accès (code porte, wifi), chambres & équipements, fenêtre de réservation.
3
Définir la commission propriétaire — Dans la fiche du bien, champ « Commission prestations (%) ». C'est la commission DPM sur les prestations internes vendues par le personnel du propriétaire.
4
Ajouter les photos — Onglet Photos du bien. 15-25 photos recommandées. La première sera la photo de couverture.
5
Configurer les tarifs saisonniers — Tarification → Tarifs saisonniers → + Ajouter. Créez une ligne pour chaque saison (haute, basse, fêtes…) avec le prix/nuit et le minimum de nuits.
6
Connecter les canaux — Gestionnaire de canaux → + Connecter un canal. Ajoutez Airbnb, Booking, VRBO. Collez les URL iCal.
7
Activer les prestations pour ce bien — Conciergerie → Options par bien. Cochez les prestations disponibles pour les voyageurs de ce bien (spa, transport, chef privé…).
8
Ajouter les prestations internes — Si le propriétaire propose ses propres services (petit-déjeuner, dîner…), allez dans sa fiche propriétaire → + Ajouter prestation. Type « interne », rattaché au propriétaire et au bien.
9
Préparer les messages automatisés — Boîte de réception → Messages automatisés → + Ajouter. Créez au minimum : instructions check-in (J-5), bienvenue (J), proposition prestations (J+2), remerciement (D+1).
10
Configurer les tâches automatiques — Tâches → Tâches automatiques. Créez « Ménage de départ » (au départ, affecté à l'agent ménage, coût du ménage).
11
Créer le compte propriétaire — Le propriétaire s'inscrit sur /proprietaire/. Validez sa demande dans Fiches & droits → Comptes, rattachez-le à sa fiche.
12
Mettre en ligne — Dans la fiche du bien, passez le statut à « en_ligne ». Le bien est visible et réservable.
✅ Vérification finale : Ouvrez le Score ASO du bien (Annonces → Score ASO) et visez un score > 80. Vérifiez que le calendrier est synchronisé avec les plateformes.

1

2
Accepter la demande — Ouvrez la réservation, vérifiez les dates et le prix, cliquez ✅ Accepter. La plateforme est notifiée.
3
Messages automatiques J-5 — 5 jours avant l'arrivée, le message d'instructions check-in est préparé en brouillon. Vérifiez-le et envoyez-le. Le voyageur reçoit : adresse, code porte, wifi, instructions.
4
Tâche ménage automatique — Si la réservation précédente vient de se terminer, une tâche ménage est créée automatiquement pour l'agent ménage. Vérifiez dans Tâches → Kanban.
5
Check-in en ligne — Le voyageur remplit son check-in en ligne (pièce d'identité, heure d'arrivée). Vérifiez dans Réservations → Check-in en ligne.
6
Jour d'arrivée — Message de bienvenue — Le message de bienvenue est préparé en brouillon avec le lien vers l'espace voyageur. Envoyez-le.
7
Pendant le séjour — Prestations — Le voyageur accède à son espace (/sejour/#/s/token), consulte le catalogue et commande des prestations. Les demandes apparaissent dans le Tableau de bord et dans Conciergerie → Demandes. Confirmez-les.
8
J+2 — Proposition de prestations — Le message automatique propose les prestations phares. Envoyez-le si le voyageur n'a encore rien commandé.
9
Jour du départ — Ménage — L'agent ménage réalise le ménage de départ. Il passe la tâche en « Fait » dans l'application. L'état de propreté du bien passe à « propre ».
10
D+1 — Remerciement — Le message de remerciement et demande d'avis est préparé. Envoyez-le.
11
Avis et relevé — Si le voyageur laisse un avis, il apparaît dans Avis. En fin de mois, les revenus de cette réservation apparaissent dans le relevé propriétaire.

C. Un partenaire rejoint DPM — intégration complète

1
Créer la fiche partenaire — Conciergerie → Partenaires → + Ajouter. Remplissez : nom, activité, contact, téléphone, email, adresse. Définissez les droits (peut modifier ses prestations ? peut créer des promotions ?).
2
Ajouter ses prestations — Conciergerie → Prestations → + Ajouter. Pour chaque prestation : type « externe », fournisseur = le partenaire, prix facturé au voyageur, net partenaire, horaires de disponibilité.
3
Activer les prestations sur les biens concernés — Conciergerie → Options par bien. Cochez les nouvelles prestations sur les biens où elles sont proposées.
4
Créer son compte — Le partenaire s'inscrit sur /partenaire/. Validez la demande dans Fiches & droits → Comptes. Rattachez le compte à sa fiche partenaire.
5
Vérifier — Utilisez « Voir son espace » dans Fiches & droits → Partenaires pour voir ce que le partenaire voit. Vérifiez que ses prestations et commandes apparaissent correctement.

D. Fin de mois — clôture et relevés

1
Vérifier les commandes en attente — Tableau de bord → vérifiez qu'il n'y a plus de commandes en « en_attente ». Confirmez ou refusez-les toutes.
2
Vérifier les dépenses — Dépenses & suppléments → vérifiez que toutes les dépenses du mois sont saisies (ménages, réparations, consommables).
3
Générer les relevés propriétaires — Relevés propriétaire → + Nouveau relevé. Sélectionnez le mois et le propriétaire (ou « tous »). Vérifiez le montant net avant de générer.
4
Vérifier les commissions partenaires — Conciergerie → Statistiques. Vérifiez le total « À reverser aux partenaires ». Préparez les virements.
5
Exporter pour la comptabilité — Rapports financiers → Export comptable. Exportez le CSV du mois pour votre comptable.
6
Consulter les statistiques — Rapports financiers → Analytique. Comparez avec le mois précédent : revenus, occupation, prix moyen.
